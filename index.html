Vooy가 원문 메타프롬프트 다섯 개를 직접 구현한 결과를 모았습니다. 열어 볼 수 있는 결과물, 구현 노트, 검증하지 못한 부분까지 함께 적었습니다.

읽기 전에. 세부 모델명과 effort는 지정받지 않아 적지 않았습니다. 공식 성능 순위나 통제 실험 점수가 아니며, 측정하지 않은 수치(fps 등)는 쓰지 않았습니다. 아래 "열림 확인"은 페이지가 열리는 것까지만 확인했다는 뜻입니다.

다섯 과제

카드의 버튼으로 결과물을 바로 열 수 있습니다.

과제 1

근정전 브릭 모션 그래픽

경복궁 근정전을 브릭 모델로 쌓고, 32초 타임라인 안에서 분해·결합 보강·인벤토리를 보여 주는 단일 HTML 모션 그래픽입니다.

  • 규모브릭 3,622개 (별도 스크립트로 집계)
  • 조작0–32초 시간 슬라이더
  • 기술three.js 0.170.0
열림 확인 · 동작·fps 미검증
열어 보기 구현 노트
과제 2

한강시 3인칭 오픈월드

가상 도시 '한강시'를 걷고 운전하는 3인칭 게임. 미션 3개와 수배 1~3단계, 낮에서 밤으로 이어지는 시간 순환이 들어 있습니다.

  • 구성다리 2개 · 고가도로 · 한글 네온 간판 8종
  • 미션배달 · 추격 따돌리기 · 옥상 레이스
  • 조작WASD · Shift · Space · F(탑승/하차)
열림 확인 · 정적 검토만 · fps 미검증
열어 보기 구현 노트
과제 3

모델 소개 스크롤 랜딩

스크롤에 따라 하나의 입자 구름이 여섯 장면으로 모양을 바꾸는 소개 페이지입니다. 모델명 자리는 원문 그대로 {{MODEL_NAME}} 입니다.

  • 장면여섯 장면 · 밝은/어두운 테마 전환
  • 입자데스크톱 8,000 / 모바일 3,800
  • 기술three.js · GSAP + ScrollTrigger
열림 확인 · 동작·fps 미검증
열어 보기 구현 노트
과제 4

단편 소설 「역상(逆像)」

2031년 서울, 폐업을 앞둔 을지로 인쇄소의 활판 인쇄공 문 씨에게 매일 밤 한 문장씩 원고가 도착하는 이야기. 다섯 장면입니다.

  • 분량본문 11,954자 (공백 포함), 약 59.8매
  • 구성다섯 장면 · 늦가을에서 첫눈까지
글자 수 집계함 · 문장 품질은 자체 판단
소설 읽기 글자 수·점검표
과제 5

USB OBS 촬영 데스크 컨트롤러

촬영 데스크용 USB 컨트롤러의 설계 일체. 요구사항, 구조, 부품 목록, 배선, 전원 예산, 펌웨어와 호스트 브리지 소스, 케이스 원본, 시뮬레이션 미리보기를 담았습니다.

  • 보드Raspberry Pi Pico 2 + OLED
  • 소스펌웨어(C) · 호스트 브리지(Python) · 케이스(OpenSCAD)
  • 제작실물 제작·시험 안 함
미리보기 열림 확인 · 컴파일·STL·실물 미검증
미리보기 설계 문서·소스

진행 방식

같은 조건으로 만든 기록이라는 점이 핵심입니다.

실행 주체

  • Vooy (모델명·effort 미지정)
  • 파일 읽기·쓰기만 되는 작업 환경에서 작성

과제 출처

  • 원문 메타프롬프트 다섯 개
  • 자리표시자는 바꾸지 않음

반영 방식

  • 결과 파일을 GitHub에 커밋
  • 파일 크기(바이트) 일치까지 대조
  • GitHub Pages로 배포

한계

이 페이지를 볼 때 알아 둘 점입니다.

  • 브라우저 실행, 컴파일, 3D 출력은 작업 환경에서 하지 못했습니다. 그래서 과제 1~3과 5의 실행 검증은 비어 있습니다.
  • 수치는 측정한 것만 적었습니다. fps와 성능 점수는 없습니다.
  • 모델 비교용 순위표가 아니라 한 번의 수행 기록입니다.
  • 스크린샷은 아직 없습니다. 실행 가능한 환경에서 확인한 뒤 추가할 예정입니다.
