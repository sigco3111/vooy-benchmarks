# REQUIREMENTS — USB OBS 촬영 데스크 컨트롤러 (프로토타입 v0.1)

상태 표기: [확정] 설계에 반영됨 / [가정] 실측 전 가정 / [미검증] 실물 또는 도구로 확인 못 함

## 1. 제품 목적
- 책상 위에 두는 소형 USB 촬영 컨트롤러 1대.
- 물리 버튼으로 OBS Studio 녹화 시작/중지와 장면(Scene) 전환을 한다.
- 촬영 중 빨간 표시등과 작은 화면에 촬영 경과 시간과 연결 상태를 보여준다.
- 표시등과 화면은 버튼을 누른 사실이 아니라 **OBS가 실제로 보고한 녹화 상태**를 따른다. [확정]

## 2. 기능 요구사항
| ID | 요구 | 근거/검증 방법 |
|---|---|---|
| F-01 | REC 버튼 1회 누름 → 녹화가 꺼져 있으면 StartRecord, 켜져 있으면 StopRecord 요청 | host/obs_bridge.py 명령 게이트 로직 |
| F-02 | SCENE 버튼 1회 누름 → OBS 장면 목록에서 다음 장면으로 전환 | host, OBS 장면 목록 순서 기준 |
| F-03 | 빨간 LED: 녹화 확인 상태에서 켜짐, 전환 중 점멸, 정지 시 꺼짐, 링크 단절 시 느린 점멸 | firmware/src/main.c 상태표, preview 시뮬레이션 |
| F-04 | OLED 128×64: 상태 한 줄, 경과 시간 HH:MM:SS, 장면 이름, 링크 상태(OK/NO OBS/NO LINK) 표시 | firmware/src/main.c 화면 구성 |
| F-05 | 링크 단절(호스트 또는 OBS 미응답) 시 화면에 NO LINK 또는 NO OBS를 명시 | 3초 무응답 타임아웃 |
| F-06 | 버튼 명령 후 OBS 확인 전까지 PEND 표시, 확인되면 실제 상태로 바꿈 | 낙관적 표시 금지 |
| F-07 | USB 연결을 기본으로 한다. 호스트 PC 브리지 앱이 OBS와 통신한다. | ARCHITECTURE.md |

## 4. 호환성 요구
- 호스트 OS: Windows 10/11, macOS, Linux 중 Python 3.10+ 가능한 환경. [미검증: 실행은 하지 않음]
- OBS Studio 31.x 계열 + 내장 obs-websocket v5 (기본 포트 4455, 비밀번호 설정 필요). [미검증: 설치 버전 확인 필요]
- 개발보드: Raspberry Pi Pico 2 (RP2350) 한 종으로 고정. Pico 2 W(무선 모델) 사용 금지.

## 5. 범위 밖
- 무선, 배터리, 상용 전원, 제품 인증(KC/FCC/CE), 양산 PCB 설계.
- OBS 이외 소프트웨어(방송 플랫폼 등) 제어.
- 주문, 구매, 발주, 배포, 커밋 등 외부 행위는 이 작업에서 하지 않는다.

## 6. 완료 판정 기준 (이 저장소 기준)
- 펌웨어 소스 전체와 CMake 빌드 설정이 있다 (컴파일은 미검증).
- 호스트 브리지 소스와 단위 테스트 파일이 있다 (실행은 미검증).
- 케이스 OpenSCAD 원본과 치수 가정/간섭 점검 표가 있다 (STL 생성은 미검증).
- 배선 회로도(SVG), 배선표, BOM(공식 출처 표기), 전원 예산이 있다.
- 단일 HTML 미리보기가 있다 (브라우저 실행은 미검증).
- 실물 인수 테스트 목록이 VERIFICATION.md에 있다.
